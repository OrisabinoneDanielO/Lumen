# UI mockups

Static HTML versions of the five screens designed on the claude.ai canvas. Open `mockups/index.html` in a browser.

- `Main.html`: show-mode main window (service plan, slide grid, preview/live, layers, library)
- `Editor.html`: edit-mode slide editor
- `Scripture.html`: scripture quick search
- `Output.html`: audience output screen
- `Stage.html`: stage display

They are visual references only: the live slide shown is fixed at Verse 2, and buttons do nothing. Sample lyrics are public-domain hymns; scripture is the World English Bible (public domain). Items in [brackets] are placeholders.
