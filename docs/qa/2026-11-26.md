# QA pass, 26 November 2026

A full check of Lumen after the first release (0.1.0) and the changes that followed it: one-click media, then Preview first; the scripture window and typing ahead; play once or loop; transitions; the fitted window.

## How it was tested

| Check | Result |
| --- | --- |
| Every automated test (44), debug and release builds, on the developer's Fedora laptop | All pass |
| CI on Windows, macOS and Linux | All pass |

| A code review of the whole operator interface by a second reviewer | 30 findings, below |

## Fixed in this pass

- **The safety keys always work.** F1–F7 (Clear, Logo, Black) used to do nothing while the library search, a popover, the scripture window or the Screens setup had the keyboard. They are now application-wide. Typed letters, numbers and Space still never change the screen while typing. *Two earlier tests (batch 5's search test and the Screens test) expected F7 to be blocked; they were updated, see decisions.md.*
- **The keyboard comes back** after closing a popover or clicking a library row or card; Escape closes the open popover.
- **Turning the output off asks first.** One click on the Main light used to end the output (the projector showed the desktop).
- **Restoring a backup asks first and says what it holds** ("12 items · 2 plans" against the library now). A restore at the first click had replaced a real library with an empty backup on the test laptop (the library before it was kept, as designed).
- **Live shows what the audience sees:** Black and the Logo cover the Live frame, and it says when the output is off.
- **A new or emptied plan clears the slide grid** (the last item's slides stayed and did nothing).
- **Page Down / Page Up skip headers** and go back to the plan after a library song or scripture. *Batch 5's Page Up test expected to land on a header; updated.*
- **Use as background** no longer reaches the screen in Edit mode.
- **Long slide text stays inside its card.**
- **Buttons that cannot act are disabled**, not only faded.
- **Plan ▾ → Delete this plan…** (with confirmation); the function existed but nothing used it.
- **Return in the library search** shows the first song found.
- **Show message…** under the Transition box opens the message panel (it did nothing); the Transition box itself now works (it only showed "Cut").
- **Scripture:** while typing ahead, a hint ("Space to complete, Enter for John 1:1") instead of an error ("Which book is j?").

## Still to do, most important first

### High

1. ~~**Screens on Linux under Wayland are unverified.**~~ *Built:* each output's real screen is checked every second; a mismatch shows on Live and in the Screens panel, which on Wayland offers to place the outputs through XWayland. Still to test with a real TV on GNOME.
2. ~~**A video that fails to load gives no sign.**~~ *Fixed:* the renderer reports videos it cannot play; Live (and Preview, for the next video) show which and why.
3. ~~**Unsaved changes can be lost without a question.**~~ *Fixed:* the theme editor and the slide editor ask Save / Discard / Keep editing before leaving changes; the slide editor follows library songs too.
4. ~~**Two Lumen windows could share one output**~~ (found while testing: closing one closed the other's output). *Fixed:* a second start brings the running window forward and quits.

### Medium

4b. **Drag and drop is missing:** songs, media and scripture into the plan, and reordering the plan by dragging (the design doc's main workflow), and the plan's "+ Add" button from the mockup.
5. **A slide card goes live on a single click,** while songs, media and plan items now go to Preview on a click. Decide whether slides follow the same rule (most presentation software sends a slide live on one click).
6. **Previous (←) only steps back on the item that is live**; once the next item is shown it does nothing.
7. **Plan actions with no plan open fail silently** (Rename, Duplicate, Export); they should be disabled or say why.
8. **Escape does not close the Plan menu, the item menu or the Transition list.**
9. **Silent failures:** a song that cannot be added to the plan, a message template with an empty field, a lower third with no name.
10. **Mockup features not built:** editing a song's arrangement and auto-split in the editor; a second translation side by side, Fit to slide and the reference position in Scripture.

### Low

11. Recent messages always show as a banner, ignoring the Ticker choice.
12. Timers and props are deleted at once, without confirmation, by a "🗑" button whose glyph may not exist in the bundled font.
13. Two features are called "logo" (the full-screen Logo, F6, and corner logos in Props); props logos keep the original file's path rather than a copy.
14. The user guide's Stage description and the jump keys: there is no key for "Tag" sections.
15. Share, Remote and Updates open on top of each other.
16. Library tabs for Scripture and Themes look available even when those parts are not loaded.
17. Enter in the first field of Timers (count up) and Props does nothing.
